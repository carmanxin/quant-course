## 使用建议

- **项目交付**:`research-report.md` 为主,`course-audit.md` 作为早期诊断参考
- **二次核对数据**:任一份均可,核心指标一致
- **实施方案**:`research-report.md` 第 5 章"三阶段实施路线图"可直接作为执行蓝图的输入
- **审稿追溯**:`guide/.research/` 子目录下保存了每章经过审稿的草稿版本(章节 1-5),可作为研究过程的痕迹
- **跨章引用**:本轮风格统一后,所有章节编号统一为阿拉伯数字(1./2./3./...),"详见第 X 节"指向明确;章节间衔接句均已加入"承上启下"块

## 注意事项

1. `_reports/` 与 `guide/.research/` 不参与 VitePress 构建
2. 引用的所有 URL 在重要场景下用户应二次核验时效
3. 报告中所有"数据显示"类陈述为 2024-2026 年内数据,过期风险自负
