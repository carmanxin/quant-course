### 关键经验
- `extract-py-fences.mjs` 不会自动跑 — 需要手动 `python scripts/build-code-index.py` 后 vitepress 才能从 `_index.json` 找到新 hash 对应的 output.json
- 修改 fence 内容(哪怕只是空白)都会改 hash — 改完必须重 extract + 重跑
- vitepress SSR 通过 `_index.json` 查 name → `${name}.output.json`,缺一不可
- safe-delete 持续触发 rm/mv 失败 → 必须 `unset NODE_OPTIONS` 才能跑 vitepress build
