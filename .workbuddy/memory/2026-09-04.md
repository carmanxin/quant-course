## 教训
1. **便携版打包脚本必须有同步步骤**:`relativize` 只重写路径,不复制文件
2. **批量扫描用 `set(idx.values())`**:VitePress `_index.json` 是 `{ path: hash }` 字典,值才是真正的 hash
3. **HTML 文本中的旧文案可能来自组件代码本身**:必须先在源码 `grep -rn` 确认
4. **summaryPrint 对容器类型要递归判断**:外层 ndarray/list 的 `__module__` 是 `numpy`,不会触发 matplotlib 检查;需遍历元素判断 `type(_e).__module__`
5. **每次修脚本后,先扫受影响的 subset**:`PRECOMPUTE_ONLY=hash,hash` 精准重跑比全站重跑快 100 倍
