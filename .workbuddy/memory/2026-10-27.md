### 三、关键方法论

- **验 Vue 组件要验「交互」，不只验「HTML 里有 class」**：SSR 静态核验只能证明渲染，
  不能证明组件已挂载（未注册组件 SSR 也会输出 class —— 那是 unknown element 的原生属性）。
  必须用 Playwright 点一下，看 `qz-verdict--ok` 是否真的出现。
- 本地预览用 `portable/dist`（相对路径化版），不要用 `.vitepress/dist`（绝对路径，
  经 HTTP 访问时资源 404）。
- 截图产物放 `.shots/`，用完清理临时脚本（`.tmp_*.mjs`）。
