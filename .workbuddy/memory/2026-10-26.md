## 续 · 三令执行与整改（2026-10-26 晚）

### 🔴 关键更正：QuizBlock「丢失」是误判，真凶是「只 import 未注册」
第一轮勘验记「`QuizBlock.vue` 已删除」——**该结论有误**。实查 git `f264546`：
组件文件一直存在且与 HEAD 逐字节一致；`theme/index.ts` 也从未删除注册行。
真正的问题（第一轮漏查、亦即 13 页测验交互失效的真因）：

> `.vitepress/theme/index.ts` 里 `import QuizBlock` 存在，但 `app.component('QuizBlock', ...)`
> **缺失** → 未注册的自定义元素在 SSR 阶段被当作未知 HTML 元素，
> Vue 不渲染它 → **内容在产物里直接消失，且构建零报错**。

- `RunLocally` 同样只 import 未注册 → 影响 **12 个页面**，产物中 `<runlocally>` 计数 0。
- 修复：两条 `app.component(...)` 补齐 → 测验与 RunLocally 提示条恢复渲染。

### ⚠ 假阴性教训（本次最贵的坑）
第一轮验证脚本 grep 的是 `QuizBlock` / `question-b64` / `quiz-option`，
但 **Vue SSR 后组件名与原始 prop 都不出现在 HTML 里**，产物中实际是
`qz-head` / `qz-badge` / `qz-opt--idle` / `qz-opt-body`。
→ 「13 页测验丢失」纯属**验证脚本自身的假阴性**，产物一直正常。
**教训：验 Vue 组件必须用组件自身的 class 名，不能用组件名/自定义 prop。**
