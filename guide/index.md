# 量化交易系统设计与实践

> 20大模块 · 107个章节 · 交互式学习 · 含名词解释

## 📌 课程简介

本课程系统讲解量化交易的完整知识体系，涵盖金融数学基础、Python 编程实战、策略开发、回测框架、投资组合管理、实盘部署等核心内容。每个章节配有名词解释、Python 代码示例和交互式计算工具。

## 模块概览

| 模块 | 内容 | 章节 |
|------|------|------|
| **模块一** | 量化交易全景与行业认知 | 发展史、策略分类、量化思维、现实挑战 |
| **模块二** | 金融基础与数理工具 | 微观结构、资产定价、概率统计、时间序列、线性模型 |
| **模块三** | Python 量化编程与数据工程 | 数据栈、数据清洗、性能优化、金融数据处理、可视化 |
| **模块四** | 回测框架与绩效评估 | 引擎原理、成本建模、绩效指标、陷阱与对策、统计检验 |
| **模块五** | 策略开发工坊 | 因子投资、双均线、统计套利、CTA趋势、事件驱动、多因子 |
| **模块六** | 投资组合管理与优化 | 均值方差、风险平价、凯利准则、中性约束、VaR |
| **模块七** | 执行算法与微观结构 | 订单类型、算法执行、做市策略、高频交易、成本分析 |
| **模块八** | 机器学习与另类数据 | 监督学习、无监督、NLP、另类数据、过拟合防御 |

| **模块十** | 前沿专题与职业成长 | 强化学习、生成式AI、暗池、团队分工、终极项目 |

## 学习路线

1. **入门**（模块一至二）：建立量化交易整体认知，掌握必要的金融数学基础
2. **工具**（模块三）：熟练使用 Python 数据栈进行金融数据处理
3. **核心**（模块四至六）：掌握回测、策略开发、投资组合管理的完整流程
4. **进阶**（模块七至八）：深入执行算法、市场微观结构、机器学习应用
5. **实战**（模块九至十）：了解实盘部署架构，完成端到端策略项目
